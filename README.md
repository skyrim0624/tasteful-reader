# Tasteful Reader

一个面向长文、书摘和深度阅读的 React + TypeScript 阅读器实验。

## 当前版本

- 书库侧栏：示例书籍、本地书籍列表与阅读进度
- 阅读区：亮暗主题、字号调节、专注模式、沉浸模式
- 本地打开：支持 TXT / Markdown 文件，正文只在浏览器本机解析，不上传远程服务
- 阅读持久化：当前书籍、导入列表、阅读进度和偏好设置保存在浏览器本机
- 动态背景：按书籍类型自动匹配低干扰动态图画，也可手动切换类型、强度和减少动态
- 响应式布局：桌面三栏，平板双栏，移动端单栏
- 暂未支持：EPUB 解析

## 开发

```bash
pnpm install
pnpm dev
```

## 验证

```bash
pnpm lint
pnpm build
```
