# Tasteful Reader

一个面向长文、书摘和深度阅读的 React + TypeScript 阅读器实验。

## 当前版本

- 书库侧栏：书籍封面、阅读进度、搜索入口
- 阅读区：纸张模式、深夜模式、字号调节、专注模式
- 页边笔记：划线摘录、笔记列表、新笔记入口
- 响应式布局：桌面三栏，平板双栏，移动端单栏

## 开发

```bash
pnpm install
pnpm dev
```

## 验证

```bash
pnpm lint
pnpm build
```
